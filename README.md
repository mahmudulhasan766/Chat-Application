# Chat Application

A Flutter-based real-time chat application developed as a technical assignment. The application provides a simple and responsive chat experience with room-based messaging, online members, and clean architecture.

## ✨ Features

- 💬 Real-time chat messaging
- 👥 Online member list
- 🟢 Online status indicator
- 📱 Responsive UI
- 🌙 Light/Dark theme support
- 🗓️ Date/day separators
- 💭 Modern message bubbles
- 🔄 BLoC state management
- 🧩 Feature-based Clean Architecture
- 🌐 Internet connectivity handling
- ♻️ Reusable and maintainable widgets
